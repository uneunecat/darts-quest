# 📘 DARTS QUEST - Game Design Document
**Version:** 1.9.1 (UI Polish)
**Last Updated:** 2024-05-XX

## 1. プロジェクト概要
* **タイトル:** DARTS QUEST
* **コンセプト:** ダーツのプレイスキル（PPR/スコア）が直接攻撃力になるRPG。
* **プラットフォーム:** Webブラウザ (PC / Mobile)

## 2. ゲームシステム仕様

### A. バトルシステム
* **基本ルール:** 1ターンにダーツを3投し、その合計スコアが基本ダメージとなる。
* **ダメージ計算:** `(Dart Score * Buffs) + (Dart Score...) - Enemy Guard`
* **WEAKシステム:** 敵固有の「弱点数値」ヒットでドロップ確定＆演出強化。
* **MPシステム:** 最大10。ターン終了時+3回復。

### B. カードシステム (v1.4 Overhaul)
* **コスト:** 個別コスト制 (0〜8)。MP不足時は使用不可。
* **デッキ:** 最大12枚 / 同名3枚まで。12枚未満の場合はカード機能ロック。

### C. UI & UX (v1.9 New)
* **Global Tooltip:** 画面端で見切れないようJS制御されたフローティング説明文。
* **Smart Deck Editor:** * 所持リスト: 効果テキストを直接表示。
    * デッキ枠: ツールチップでのみ詳細表示。
    * 自動ソート: ID順に並び替え。
