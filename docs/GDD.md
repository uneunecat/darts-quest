# 📘 DARTS QUEST - Game Design Document
**Version:** 2.3 (God's Trial Update)
**Last Updated:** 2024-05-XX

## 1. プロジェクト概要
* **タイトル:** DARTS QUEST
* **コンセプト:** ダーツのプレイスキル（PPR/スコア）が直接攻撃力になるRPG。
* **プラットフォーム:** Webブラウザ (PC / Mobile)

## 2. ゲームシステム仕様 (v2.3 Updated)

### A. ステージ構成
| ID | Stage Name | Boss | 特徴 |
|:---|:---|:---|:---|
| 1 | 旅立ちの森 | グレート・モス | 基本操作 |
| 2 | 荒れ狂う荒野 | 剣竜 | 2回攻撃 |
| 3 | 誘惑の迷宮 | ハーピィズペット竜 | 誘惑(MP吸収), 拘束 |
| 4 | 幻想の狂宴 | サウザンド・アイズ | トゥーン(無効化), 吸収 |
| **5** | **EXTRA** | **真紅眼の黒竜** | **超高HP, 黒炎弾** |
| **6** | **神の試練** | **オシリスの天空竜** | **召雷弾(20以下無効), 再生, 封印** |

### B. バトルシステム
* **基本:** 1ターン3投。合計スコア＝ダメージ。
* **召雷弾 (New):** Stage 5 Boss固有。単発20以下のダメージを0にする。
* **状態異常:**
    * **Stun:** 行動不能。
    * **Seal (粘着):** カード・アイテム使用不可。
* **リソース:**
    * **MP:** 毎ターン+3。最大10。
    * **Hand:** 毎ターン1ドロー。最大5枚。
    * **Deck:** 20枚固定。

### C. 報酬・進行
* **DP計算:** `(スコアDP × ステージ倍率) + ランクボーナス`
    * 倍率: S1(x1.0) 〜 S5/Ex(x5.0)
* **ステータス引き継ぎ:** HP/MP/手札/山札/アイテムを持ち越し。
