# 📘 DARTS QUEST - Game Design Document
**Version:** 2.1.2 (System Overhaul)
**Last Updated:** 2024-05-XX

## 1. プロジェクト概要
* **タイトル:** DARTS QUEST
* **コンセプト:** ダーツのプレイスキル（PPR/スコア）が直接攻撃力になるRPG。
* **プラットフォーム:** Webブラウザ (PC / Mobile)

## 2. ゲームシステム仕様 (v2.1 Updated)

### A. バトル & リソース
* **基本ルール:** 1ターンにダーツを3投。合計スコアがダメージ源。
* **ドローシステム:** 毎ターン開始時（MP回復時）に山札から1枚ドロー。撃破時にもドロー発生。
* **手札/デッキ:**
    * 最大手札: **5枚**
    * デッキ枚数: **20枚** (固定)
    * 同名カード制限: 3枚まで
    * **Hard Mode:** デッキが20枚未満の場合はカード機能ロック。
* **MPシステム:** 最大10。ターン終了時 +3回復。

### B. カードシステム
* **Pack Vol.1 (Legend):** Stage 1解放。基本魔法・罠。
* **Pack Vol.2 (Awakening):** **Stage 3**解放。テクニカル（ハンデス、反射、蘇生）。

### C. 報酬・進行
* **DP計算:** `(スコアDP × ステージ倍率) + ランクボーナス`
* **ステータス引き継ぎ:** 「次へ進む」選択時、HP/MP/手札/山札/アイテムを持ち越し。

### D. UI & UX
* **Deck Editor:** 左右2カラム（PC）/ 上下スタック（スマホ）。所持カードはテキスト直接表示。
* **Visuals:** ドロー・回復時にフローティングテキスト演出。
